# Changelog

## 1.0.0 – первый выпуск

- Сохранение настроек одного персонажа как шаблона; другие персонажи проверяют и применяют его при входе в игру
- Окно проверки с «до → после» и пояснением для каждой настройки; снимите отметку с того, что вам не нужно
- Разделы: настройки интерфейса для каждого персонажа, окна и цвета чата, макет режима редактирования, назначение клавиш, включённые модификации, профили модификаций на Ace3
- Шаблоны классов для макросов персонажа и панелей команд, применяются только к персонажам того же класса
- По желанию: персонажи-шаблоны обновляют шаблон автоматически (раз в минуту и при выходе)
- Положение окон и кнопок у миникарты всех аддонов, сбрасывается сразу
- Раздел «Настройки аккаунта» (по желанию): каждое изменение с момента входа с прежним значением – принять или сбросить
- Сброс отдельных записей или всего сразу; отмена последнего применения
- Сворачиваемые разделы с отметкой для каждого; исключённые настройки можно снова отметить
- Кнопка у миникарты, окно с изменяемым размером, `/charsync icon`
