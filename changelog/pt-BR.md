# Changelog

## 1.0.0 – primeira versão

- Salve as configurações de um personagem como modelo; os outros personagens revisam e aplicam ao entrar no jogo
- Janela de revisão com antes → depois e uma explicação para cada configuração; desmarque o que não quiser
- Seções: opções de interface por personagem, janelas e cores do bate-papo, layout do Modo de Edição, atalhos de teclado, addons ativados, perfis de addons Ace3, configurações do MyCharForever
- Modelos de classe para macros do personagem e barras de ação, aplicados só a personagens da mesma classe
- Personagens modelo atualizam seu modelo automaticamente ao sair do jogo
