# CharSync

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

把一個角色設定成你喜歡的樣子——其他所有角色都會得到相同的設定。CharSync會逐項顯示哪些內容會變更（之前 → 之後）以及每項變更的作用，你可以略過任何不想要的內容。

適用於 **WoW Forever**。使用你遊戲用戶端的語言：英文、德文、法文、西班牙文、葡萄牙文、義大利文、俄文、韓文與中文（簡體與繁體）。

## 使用方式

1. 以你希望其設定套用到所有角色的那個角色登入，開啟 `/charsync` 並點擊 **「儲存為通用範本」**。
2. 巨集與快捷列請為每個職業儲存一次 **職業範本**——它們只會同步給同職業的角色。
3. 其他角色登入時，CharSync會開啟檢查視窗：列出每一處差異的之前 → 之後及說明。取消勾選你不想要的內容，然後點擊 **「套用已勾選項目」**。

插件無法寫入其他角色的檔案，因此範本以帳號通用方式儲存，並在每個角色登入時套用。

## 可同步的內容

- WoW依角色儲存的介面選項（額外快捷列、個人資源顯示、任務等級、團隊框架選項、世界地圖、小地圖）
- 聊天視窗（名稱、字型大小、背景、訊息類型、頻道）與聊天顏色
- 目前的編輯模式版面配置
- 按鍵設定
- 啟用了哪些插件
- 透過 Ace3 函式庫儲存設定的插件的設定檔
- 角色巨集與快捷列——僅限同職業
- 視窗位置（移動過的 WoW 與插件視窗）以及小地圖按鈕的位置

圖形、音效、大部分介面選項與幾乎所有插件設定在WoW中本來就是帳號通用的。

## 選項

- 開啟或關閉整個類別。
- 取消勾選單項設定，即永不再同步該設定（適用於所有角色）。
- 自動儲存範本（預設關閉）：僅在有變更時，每分鐘一次並在登出時儲存。
- 不經確認直接套用新範本。
- 「帳號通用設定」類別（預設關閉）：勾選後，對所有角色生效的設定（帳號通用的插件設定與 WoW 設定）的每項變更都會連同之前的值顯示，可逐項接受或重設。
- 每個項目都可單獨重設。在範本角色上，儲存後的變更可逐項寫入範本（**「寫入範本」**）。上一次套用可以復原（**「復原」**）。
- 可摺疊各區段；標題中的勾選框會勾選其中全部內容。
- **「已排除的設定」**列出你排除的全部內容——勾選即可恢復。

指令：`/charsync`、`/charsync save`、`/charsync saveclass`、`/charsync apply`, `/charsync icon` (找回小地圖按鈕)
