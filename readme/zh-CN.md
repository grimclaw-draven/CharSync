# CharSync

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

把一个角色设置成你喜欢的样子——其他所有角色都会获得相同的设置。CharSync会逐项显示哪些内容会改变（之前 → 之后）以及每项更改的作用，你可以跳过任何不想要的内容。

适用于 **WoW Forever**。使用你游戏客户端的语言：英语、德语、法语、西班牙语、葡萄牙语、意大利语、俄语、韩语和中文（简体和繁体）。

## 使用方法

1. 用你希望其设置适用于所有角色的那个角色登录，打开 `/charsync` 并点击 **“保存为通用模板”**。
2. 对于宏和动作条，请为每个职业保存一次 **职业模板**——它们只会同步给同职业的角色。
3. 其他角色登录时，CharSync会打开一个检查窗口：列出每一处差异的之前 → 之后及说明。取消勾选你不想要的内容，然后点击 **“应用已勾选项”**。

插件无法写入其他角色的文件，因此模板以账号通用方式保存，并在每个角色登录时应用。

## 可同步的内容

- WoW按角色保存的界面选项（额外动作条、个人资源显示、任务等级、团队框架选项、世界地图、小地图）
- 聊天窗口（名称、字体大小、背景、消息类型、频道）和聊天颜色
- 当前的编辑模式布局
- 按键设置
- 启用了哪些插件
- Ace3插件的配置文件（AtlasLoot、Questie、SilverDragon……）
- MyCharForever设置，包括小地图按钮位置
- 角色宏和动作条——仅限同职业

图形、声音、大多数界面选项和几乎所有插件设置在WoW中本来就是账号通用的。

## 选项

- 开启或关闭整个类别。
- 取消勾选单项设置，即永不再同步该设置（对所有角色生效）。
- 将某个角色设为模板角色：它每次登出时都会更新模板。
- 无需确认直接应用新模板。

命令：`/charsync`、`/charsync save`、`/charsync saveclass`、`/charsync apply`
