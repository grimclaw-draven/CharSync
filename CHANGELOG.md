# Changelog

## 1.0.1

- The addon list shows the version number instead of "@project-version@"

## 1.0.0 – first release

- Save the settings of one character as a template; other characters review and apply it when they log in
- Review window with before → after and an explanation for every setting; untick what you don't want
- Sections: per-character interface options, chat windows and colors, Edit Mode layout, key bindings, enabled addons, Ace3 addon profiles
- Class templates for character macros and action bars, applied only to characters of the same class
- Optional: template characters update their template automatically (once a minute and at logout)
- Window positions and minimap button positions of all addons, reset right away
- Section "Account-wide settings" (optional): every change since login with its previous value – accept or reset
- Reset single entries or everything at once; undo the last apply
- Collapsible sections with a tick per section; excluded settings can be ticked again
- Minimap button, resizable window, `/charsync icon`
